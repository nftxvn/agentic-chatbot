# Project Rules & Guidelines

## Git Policy (STRICT & PERMANENT)
- **DILARANG MELAKUKAN `git push` TANPA PERSETUJUAN EKSPLISIT DARI USER.**
- Asisten TIDAK BOLEH mengeksekusi perintah `git push` (ke remote mana pun atau branch mana pun) secara otomatis atau tanpa konfirmasi/permintaan eksplisit dari pengguna.
